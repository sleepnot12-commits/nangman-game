이 분석은 정해진 가격 변동 가정만 적용한 정적 시뮬레이션입니다. 레버리지 ETF 일간 재설정, 상관관계 변화, 수수료, 세금, 환율 변동은 반영하지 않습니다. 투자 권유나 자동매매 시스템이 아닙니다.

데이터는 입력 중 브라우저 메모리에서만 계산하며 서버에 전송하거나 저장하지 않습니다. 공개 GitHub Pages에 계좌번호·API 키·개인 정보 입력 금지.
